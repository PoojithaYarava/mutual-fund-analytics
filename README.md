# Bluestock Mutual Fund Analytics Capstone

Mutual fund analytics project with Python ETL, SQLite warehouse, and reporting outputs.

## Layout

- `etl/` data processing scripts
- `sql/` warehouse schema and queries
- `data/raw/` source files
- `data/processed/` generated outputs
- `tests/` warehouse checks

## Main Entry Points

- `python main.py`
- `python analytics_cli.py`
- `python tests/test_warehouse.py`
